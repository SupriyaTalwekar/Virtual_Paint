# Virtual Paint with Hand Gestures

A real-time virtual paint application that allows you to draw on the screen using hand gestures detected via a webcam. Built using **Python**, **OpenCV**, and **MediaPipe**.

---

## Features

- Draw on screen using **index finger**.
- **Change brush color** by showing **two fingers**.
- **Clear canvas** by showing **three fingers**.
- Real-time hand tracking with MediaPipe.
- Smooth drawing with customizable brush thickness and colors.

---

## Requirements

- Python 3.7+
- OpenCV
- MediaPipe
- NumPy
